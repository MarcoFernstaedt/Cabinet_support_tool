| Location | What it contains | Authority |

| [`spec/`](spec/00-README.md) | Architecture, security model, protocol, and agent, server, and console specifications. | **Source of truth.** The specification defines product behaviour. |

| [`codex-tasks/`](codex-tasks/) | Working briefs written before individual changes, with occasional results records. | **Working briefs.** Use them to understand what was requested for a piece of work. The product documentation lives in the sections above. |
